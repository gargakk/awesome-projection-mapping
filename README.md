# Awesome Projection Mapping [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of projection mapping software, hardware, tutorials, and resources for visual artists and VJs.

Projection mapping (also called video mapping) is a projection technique used to turn objects into display surfaces for video projection.

## Software

### Professional

- [MadMapper](https://madmapper.com) - Industry-standard projection mapping software (macOS/Windows) - €599
- [Resolume Arena](https://resolume.com) - VJ software with advanced projection mapping - €599
- [HeavyM](https://heavym.net) - User-friendly projection mapping with real-time effects
- [Smode](https://smode.fr) - Real-time 3D compositor and mapping tool
- [Millumin](https://www.millumin.com) - Creative software for live performances (macOS)

### Browser-Based

- [4mapper](https://4mapper.com) - Professional browser-based projection mapping with live widgets and Arduino integration - Free trial + €39 PRO

### Free & Open Source

- [MapMap](https://mapmapteam.github.io/) - Open source video mapping software
- [VPT (Video Projection Tool)](https://hcgilje.wordpress.com/vpt/) - Free multipurpose realtime projection software
- [Splash](https://gitlab.com/sat-metalab/splash) - Free modular mapping software for distributed setups

### Programming/Creative Coding

- [TouchDesigner](https://derivative.ca) - Node-based visual programming for multimedia
- [Processing](https://processing.org) with Projection Mapper library
- [VVVV](https://vvvv.org) - Hybrid visual/textual programming for multimedia

## Hardware

### Projectors

- Short-throw projectors for small spaces
- Long-throw projectors for large installations
- Laser projectors for 24/7 installations

### Controllers

- [Arduino](https://arduino.cc) - Microcontroller for sensor integration
- [Raspberry Pi](https://raspberrypi.org) - Single-board computer for standalone installations
- MIDI controllers for live performance
